GULDGRAVER47 GUIDE - SIMPLE WEBSITE
====================================

HOW TO OPEN:
1. Extract the ZIP file.
2. Double-click index.html or open it with VS Code Live Preview.
3. Click Jax or Urgot to see the separate opponent lists.
4. Click an opponent to show the runes and items.

HOW TO EDIT:
- index.html: homepage text, links, champion pictures.
- style.css: background color, star positions, shape sizes and spacing.
- matchups.js: Jax runes and items for all 48 opponents.
- urgot-matchups.js: Urgot runes and items for all 48 opponents.
- jax.html / urgot.html: headings and page text.

TIP: Ctrl + S in VS Code, then refresh your preview.
You do not need to install HTML, CSS or JavaScript.
The champion and build pictures are pulled from Riot Data Dragon,
so pictures require internet access.
Urgot builds are starting examples, not live matchup statistics.

PUBLIC HOSTING: Upload the unzipped folder to a static hosting provider
such as Netlify Drop, then share the published link.
